## 💡 使い方のヒント

### 毎日の基本的な流れ

```
1. 出勤時
   ログイン → 出勤打刻

2. 業務中
   （必要に応じて勤怠履歴確認）

3. 退勤時
   退勤打刻 → ログアウト
```

### セキュリティのために

- 作業終了後は必ずログアウトしてください
- 共有PCを使用する場合は特に重要です
- パスワードは他人に教えないでください

### 困ったときは

1. [トラブルシューティング](guides/troubleshooting.md)を確認
2. [FAQ](FAQ.md)を確認
3. それでも解決しない場合は管理者に連絡
