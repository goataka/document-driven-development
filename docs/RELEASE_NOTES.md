# リリースノート

## バージョン 1.0.0 (予定)

**リリース日**: 未定

### 🎉 新機能

#### 認証機能
- **ユーザー登録**: メールアドレスとパスワードによる新規アカウント作成
  - 氏名、メールアドレス、パスワード、会社コードの入力
  - メールアドレス確認機能
  - パスワード強度チェック
- **ユーザーログイン**: メールアドレスとパスワードによる安全なログイン機能
- **セッション管理**: ログイン状態の維持とセキュアなログアウト機能

#### 勤怠打刻機能
- **出勤打刻**: ワンクリックで出勤時刻を記録
- **退勤打刻**: ワンクリックで退勤時刻を記録
- **打刻時刻の自動記録**: システム時刻を使用した正確な時刻記録

#### 勤怠履歴機能
- **個人勤怠一覧**: ログインユーザー自身の打刻履歴を表示
- **日付範囲指定**: 期間を指定した勤怠記録の閲覧
- **勤務時間の自動計算**: 出勤・退勤時刻から勤務時間を自動算出

### 🔒 セキュリティ

- パスワードの暗号化保存
- セッションベースの認証
- 個人情報保護（ユーザーは自分のデータのみ閲覧可能）

### 💻 技術仕様

- **対応ブラウザ**: 
  - Google Chrome (最新版)
  - Mozilla Firefox (最新版)
  - Microsoft Edge (最新版)
  - Safari (最新版)

- **推奨環境**:
  - インターネット接続必須
  - JavaScript有効化必須
