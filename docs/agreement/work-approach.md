# 作業の進め方

このドキュメントは、プロジェクトでの作業を進める際の基本原則を定義します。

## 基本原則

- 変更は最小限に抑える
- 既存のパターンに従う
- 不明な点は確認を求める

## 変更の進め方

### 小さな変更単位

- 小さく、明確な変更単位で作業する
- 関連する変更は1つのコミットにまとめる
- 無関係な変更は別のブランチで行う

### パターンの踏襲

- プロジェクト内の既存のコードやドキュメントのパターンを確認する
- 一貫性のあるスタイルを保つ
- 新しいパターンを導入する場合は事前に相談する

### コミュニケーション

- わからないことがあれば遠慮なく質問する
- 大きな変更を行う前にIssueやディスカッションで相談する
- レビュアーのフィードバックには必ず対応する
