# コミュニケーション規約

このドキュメントは、プロジェクト全体で統一されたコミュニケーション方法を定義します。

## 使用言語

すべてのコミュニケーションは**日本語**で行います：

- Issue
- プルリクエスト
- コミットメッセージ
- ドキュメント
- コードコメント

## 質問・相談

- **GitHub Issues**: バグ報告、機能要望、質問
- **Pull Request**: コードレビュー、設計相談
- **GitHub Discussions**: 一般的な議論、アイデア共有（有効化されている場合）

## レスポンス時間

- 緊急でない質問: 2-3営業日以内
- 緊急の問題: 24時間以内

## 行動規範

- 尊重と礼儀を持って接する
- 建設的なフィードバックを心がける
- 多様な意見を尊重する
- 初心者に優しく、学習を支援する
