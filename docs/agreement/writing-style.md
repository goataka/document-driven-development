# 文章スタイル規約

このドキュメントは、プロジェクト全体で統一された文章スタイルを定義します。

## 箇条書きの使用

- 情報は箇条書きで整理する
- 各項目は簡潔に記述する
- ネストは必要最小限にとどめる

## 文章の長さ制限

- 1つの文章は最大3文以内とする
- 3文を超える場合は段落やブロックを分ける
- 長い説明が必要な場合は小見出しを使用する

## 例：適切な文章構造

```markdown
## 機能概要
本システムは勤怠管理を行います。ユーザーは出退勤を記録できます。履歴の閲覧も可能です。

## 主な機能
- 出勤・退勤の打刻
- 勤怠履歴の閲覧
- 月次レポートの生成
```

## 文体

### ドキュメント
- 対象者に応じた適切な文体を選択する
- ユーザー向け: 丁寧語（です・ます調）
- 開発者向け: 簡潔で技術的な表現

### コードコメント
- 簡潔な体言止めまたはです・ます調
- 過剰なコメントは避ける

### コミットメッセージ
- 簡潔な記述
- 日本語で記述する
