# フロントエンドデプロイ方針

本ドキュメントは、フロントエンドのデプロイ方針と静的サイト配信戦略を説明します。

---

## デプロイ方針

### 基本戦略

**静的サイトホスティング（S3 + CloudFront）の採用**:
- コスト最適化: 低コストで高性能配信
- グローバル配信: CloudFront CDNで低レイテンシ
- 高可用性: AWS管理の冗長化
- シンプルな構成: サーバー管理不要

---

## 環境別デプロイ方針

### 1. ローカル環境
**方針**:
- Vite開発サーバーで実行
- ホットリロードで開発効率化
- コストゼロ

**特徴**:
- ポート: localhost:5173
- API接続: ローカルバックエンドまたはモックAPI
- 環境変数で設定切り替え

### 2. CI環境
**方針**:
- ビルド検証のみ
- 静的ファイル生成確認
- GitHub Actions無料枠内

**プロセス**:
- npm run build実行
- ビルドエラーチェック
- アーティファクト保存

### 3. 検証環境（AWS）
**方針**:
- 自動デプロイ（mainブランチ）
- 低コスト運用

**構成**:
- S3バケット: 静的ファイルホスティング
- CloudFront: CDN配信
- Route 53: カスタムドメイン（オプション）

**コスト目安**: 月額 $1-5

### 4. ステージング環境（AWS）
**方針**:
- 本番前の最終検証
- 本番同等構成

**構成**:
- S3 + CloudFront
- 本番と同じビルド設定
- SSL/TLS証明書

**コスト目安**: 月額 $2-8

### 5. 本番環境（AWS）
**方針**:
- 高パフォーマンス配信
- グローバルアクセス最適化

**構成**:
- S3バケット（プライベート）
- CloudFront（エッジロケーション活用）
- ACM証明書（無料SSL/TLS）
- WAF（必要時）

**コスト目安**: 月額 $5-20（トラフィック次第）

## CloudFront CDN戦略

### キャッシュ方針
- 静的アセット: 長期キャッシュ（1年）
- HTMLファイル: 短期キャッシュ（5分）
- APIコール: キャッシュなし

### キャッシュ無効化
- デプロイ時に自動無効化
- 特定パスのみ無効化（コスト削減）
- バージョン管理でキャッシュバスティング

### エッジロケーション
- 全世界のエッジロケーション活用
- 日本・アジア地域優先
- レイテンシ最小化

---

## ビルド最適化方針

### バンドルサイズ削減
- コード分割: ルートベース
- 遅延ロード: 必要時に読み込み
- Tree Shaking: 未使用コード削除

### アセット最適化
- 画像圧縮: WebP形式活用
- フォント最適化: サブセット化
- CSS/JS圧縮: Minify有効

---

## デプロイフロー

### 自動デプロイ
1. コードプッシュ → GitHub Actions実行
2. ビルド実行（npm run build）
3. S3へファイルアップロード
4. CloudFront無効化
5. ヘルスチェック実行

### ロールバック方針
- S3バージョニング有効化
- 前バージョンへ即座に復帰可能
- CloudFront無効化で反映

---

## セキュリティ方針

### アクセス制御
- S3バケット: パブリックアクセス禁止
- CloudFront: Origin Access Identity使用
- HTTPS強制: HTTP → HTTPSリダイレクト

### セキュリティヘッダー
- Content-Security-Policy設定
- X-Frame-Options設定
- Strict-Transport-Security設定

### WAF（本番のみ）
- DDoS攻撃対策
- SQLインジェクション防御
- XSS攻撃防御

---

## パフォーマンス最適化

### Core Web Vitals目標
- LCP: < 2.5秒
- FID: < 100ms
- CLS: < 0.1

### 最適化施策
- 画像遅延ロード
- フォント表示最適化
- Critical CSS インライン化
- Prefetch/Preload活用

---

## コスト最適化

### S3コスト削減
- ライフサイクルポリシー: 古いバージョン削除
- インテリジェント階層化（大量ファイル時）

### CloudFrontコスト削減
- キャッシュヒット率向上
- 圧縮有効化（Gzip/Brotli）
- リージョン制限（必要時）
