## セマンティックバージョニング

バージョン番号は `MAJOR.MINOR.PATCH` の形式を採用します。

```
例: 2.3.5
    │ │ │
    │ │ └─ PATCH: バグ修正
    │ └─── MINOR: 新機能追加（後方互換）
    └───── MAJOR: 破壊的変更
```

## バージョンの決定基準

### MAJOR バージョンアップ
- APIの破壊的変更
- データベーススキーマの大幅変更
- 主要な技術スタックの変更
- ユーザーインターフェースの全面刷新

### MINOR バージョンアップ
- 新機能の追加
- 既存機能の拡張
- パフォーマンス改善
- 非破壊的なAPI追加

### PATCH バージョンアップ
- バグ修正
- セキュリティパッチ
- ドキュメント修正
- 軽微なUI調整
