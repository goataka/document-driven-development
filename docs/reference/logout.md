# ログアウト機能リファレンス

## 概要

システムからログアウトして、ログイン画面に戻ります。

## 操作手順

1. 画面右上のユーザー名をクリックします
2. ドロップダウンメニューが表示されます
3. **「ログアウト」**を選択します
4. ログイン画面に戻ります

![ログアウト](../images/logout.svg)

## セキュリティ上の推奨事項

✅ **必ずログアウトしてください**
- 作業が終わったら必ずログアウトしてください
- 共有PCを使用している場合は特に重要です
- 離席する際も、短時間であってもログアウトすることを推奨します

⚠️ **自動ログアウト**
- 一定時間操作がない場合、自動的にログアウトされます（30分）
- 自動ログアウト後は、作業中のデータは保存されています
- 再ログイン後、前回の画面から継続できます

## 注意事項

- ログアウト前に、すべての操作が完了していることを確認してください
- 打刻処理中などの場合は、処理が完了するまで待ってからログアウトしてください
