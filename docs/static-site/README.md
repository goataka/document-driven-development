# 静的サイト - 概要

このドキュメントは、リリースノートやマニュアルを静的サイトとして提供するための方針を説明します。

## 目的

- ユーザー向けドキュメント（リリースノート、マニュアル）をMarkdown形式で作成
- 静的サイトジェネレーターを使用してWebサイトとして公開
- 認証なしで誰でもアクセス可能
- アプリケーション機能内から直接リンク

## 対象ドキュメント

以下のドキュメントを静的サイトとして提供します：

### リリースノート
- `docs/user/RELEASE_NOTES.md` - ユーザー向けリリースノート
- `docs/release/` - 開発者向けリリース管理情報

### ユーザーマニュアル
- `docs/user/MANUAL.md` - マニュアルトップページ
- `docs/user/guides/` - 各種ガイド
- `docs/user/reference/` - 機能リファレンス
- `docs/user/FAQ.md` - よくある質問

## 静的サイトジェネレーターの選択

以下のツールを推奨します：

### 1. MkDocs（推奨）
- **特徴**: Python製、シンプルで使いやすい
- **テーマ**: Material for MkDocs（美しく、レスポンシブ）
- **適用対象**: ユーザーマニュアル、FAQ

### 2. VitePress
- **特徴**: Vue.js製、高速でモダン
- **テーマ**: デフォルトテーマが洗練されている
- **適用対象**: 技術ドキュメント、開発者向けドキュメント

### 3. Docusaurus
- **特徴**: React製、Facebook製のドキュメントツール
- **テーマ**: 機能豊富、バージョニング対応
- **適用対象**: 大規模なドキュメントサイト

## ディレクトリ構成

```
document-driven-development/
├── docs/
│   ├── static-site/          # 静的サイト方針（このディレクトリ）
│   │   ├── README.md         # 概要
│   │   ├── DEPLOYMENT.md     # デプロイ戦略
│   │   ├── STRUCTURE.md      # サイト構造
│   │   └── INTEGRATION.md    # アプリ連携
│   ├── user/                 # ユーザー向けドキュメント
│   └── release/              # リリース情報
└── static-sites/             # 静的サイト生成用設定（予定）
    ├── user-docs/            # ユーザーマニュアルサイト
    └── release-notes/        # リリースノートサイト
```

## 主要な特徴

### 認証不要
- 静的サイトは認証なしで公開
- 誰でもアクセス可能なパブリックURL
- セキュリティリスクが低い内容のみ公開

### アプリケーション連携
- アプリ内の「ヘルプ」ボタンから静的サイトへリンク
- 機能ごとに関連するマニュアルページへ直接リンク
- リリースノートは新機能リリース時に案内

### 更新の自動化
- Markdownファイル更新時、自動的に静的サイトを再生成
- CI/CDパイプラインで自動デプロイ
- GitHubへのプッシュがトリガー

## メリット

1. **高速**: 静的HTMLのため表示が高速
2. **安全**: サーバーサイド処理がないため攻撃面が少ない
3. **低コスト**: 静的ファイルホスティングは無料または低価格
4. **スケーラブル**: CDN経由で世界中に高速配信
5. **シンプル**: 認証・データベース不要
