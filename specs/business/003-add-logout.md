# ログアウト機能 変更仕様書

## 変更概要

ログイン中のユーザーがシステムからログアウトして、セッションを終了する機能を実装します。

## ユーザー向け情報

### Why（なぜこの機能が必要か）

セキュアにシステムから退出するために必要です。ログアウトすることで：
- セッションを完全に終了できます
- 他の人が勝手にアクセスできなくなります
- 共有PCでも安全に使用できます

### What（何が追加されるか）

**ログアウト機能**が追加されます。

ユーザー名をクリックすると表示されるメニューから：
- 「ログアウト」を選択してセッションを終了できます
- 自動ログアウト（30分無操作）で自動的に安全な状態になります

### How（どのように使うか）

1. 画面右上のユーザー名をクリック
2. 表示されるメニューから「ログアウト」を選択
3. ログイン画面に戻ります

詳細な使い方は[ユーザーマニュアル](../../../docs/user/MANUAL.md)を参照してください。

### API仕様

#### エンドポイント
- **URL**: `POST /api/auth/logout`
- **Authorization**: Bearer token required

#### レスポンス

**成功時 (200 OK)**
```json
{
  "success": true,
  "message": "ログアウトしました"
}
```

### セキュリティ

- JWTトークンをブラックリストに追加
- ローカルストレージからトークン削除
- 自動ログアウト: 30分間無操作
